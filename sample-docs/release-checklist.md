# Thursday release checklist

Do these steps in order. Stop if a step fails.

1. Pull `main` and run the smoke suite. It must pass.
2. Play the first three levels from a fresh save.
3. Bump the build label to `lantern-YYYYMMDD` using today's date.
4. Write five bullet notes: what changed, what to look for, and known issues.
5. Upload the build to the shared drive folder named `thursday-builds`.
6. Post the notes in the `#thursday` channel before 16:00 Pacific.

If the smoke suite fails, do not upload. Say so in `#thursday` and leave the previous build in place.

The on-call person for the hour after ship is whoever opened the upload. They watch for "the build does not launch" and nothing else. Balance tweaks wait until next week.
