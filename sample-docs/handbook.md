# Lumen Finch Games — Studio Handbook

Lumen Finch Games is a five-person studio in Portland. We make Paper Lanterns, a cozy puzzle game about restoring street lamps in a hillside town.

## Hours

Core hours are 10:00–16:00 Pacific Time. Outside that window, reply when you can. We do not expect messages after 18:00.

## Ship day

We ship the weekly playable build on Thursday. The cutoff is 16:00 Pacific. After cutoff, fixes wait for the next Thursday unless the build does not launch at all.

## Reviews

Every gameplay change needs one review from someone who did not write it. Design notes live on the task, not only in chat.

## Tools

Source control is git. The internal engine is called Lantern. Do not commit build folders, local save files, or anything from `.rag_store`.

## Studio space

The studio kitchen is on the second floor. Desks are first come, first served, except the window desk, which is reserved for playtests.
