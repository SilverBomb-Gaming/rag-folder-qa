# How we decide

These are the rules we use when a call is close.

1. Players should finish a level feeling clever, not stuck.
2. We would rather cut a feature than ship a confusing one.
3. Credit is shared. The Thursday build notes list the team, not a single hero.
4. We do not crunch. If Thursday is at risk on Wednesday afternoon, we shrink scope instead of staying late.
5. A bug that blocks the first three levels outranks a new lamp design.

Paper Lanterns is set in the town of Bramble Ridge. The player repairs lamps. The town has no combat, no inventory shop, and no spoken dialogue — the story is on signs and in the light.
